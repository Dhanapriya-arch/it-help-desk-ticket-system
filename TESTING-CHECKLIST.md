# Testing checklist

- [ ] Create a ticket with all required fields.
- [ ] Edit an existing ticket and save it.
- [ ] Assign a technician and add troubleshooting notes.
- [ ] Add resolution / next-step notes.
- [ ] Change status to In Progress and then Resolved.
- [ ] Confirm resolved date is set and dashboard counts update.
- [ ] Search by ID, requester, issue, or technician.
- [ ] Filter by status and priority.
- [ ] Export CSV and open it in Excel.
- [ ] Refresh browser and confirm records persist.
- [ ] Test at mobile width.
- [ ] Reset sample data.
