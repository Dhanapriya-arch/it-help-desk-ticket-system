How to use this demo

1. Create a ticket. 2. Assign a technician. 3. Add troubleshooting notes and a resolution. 4. Update the status. 5. Search or filter tickets. 6. Export a CSV file to open ticket data in Excel.

Sample tickets are fictional. This project has no server, authentication, database, email notifications, or role-based access controls.
